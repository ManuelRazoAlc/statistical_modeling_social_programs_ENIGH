# Raw data

This folder stores the original ENIGH 2022 household-level microdata used in this project.

The main raw input file for the current version of the analysis is:

- `concentradohogar.csv`

This file was downloaded from the official INEGI ENIGH 2022 microdata section.

## Data source

**Source:** Instituto Nacional de Estadística y Geografía (INEGI)  
**Survey:** Encuesta Nacional de Ingresos y Gastos de los Hogares 2022 (ENIGH 2022)  
**Microdata file used:** `concentradohogar.csv`  
**Unit of analysis:** Household

Official ENIGH 2022 page:

https://www.inegi.org.mx/programas/enigh/nc/2022/

## Why this file is used

The `concentradohogar.csv` file contains household-level information needed to build the modeling dataset, including:

- household identifiers;
- geographic and locality variables;
- socioeconomic stratum;
- household composition;
- income components;
- government benefits income;
- expenditure variables;
- survey expansion factor.

This project uses this file to construct a household-level binary classification target:

- `received_government_benefits = 1` if the household reports positive income from government benefits;
- `received_government_benefits = 0` otherwise.

## Important note about raw files

Raw data files should remain unchanged.

All transformations, derived variables and cleaned modeling datasets are generated by the scripts and saved in:

```text
data/processed/
docs/
outputs/
```

The raw file is preserved in its original form so the analysis can be reproduced from the same starting point.

## Expected file

Before running the scripts, place the following file in this folder:

```text
data/raw/concentradohogar.csv
```

The first script expects this exact path:

```text
data/raw/concentradohogar.csv
```

## Reproducibility

To reproduce the analysis from the raw file, run the scripts from the project root directory in this order:

```bash
python3 scripts/01_prepare_enigh_data.py
python3 scripts/02_exploratory_analysis.py
python3 scripts/03_logistic_regression_model.py
python3 scripts/04_model_comparison.py
python3 scripts/05_threshold_analysis.py
```
